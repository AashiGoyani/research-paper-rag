Key Concepts Explained Simply

Embeddings

Converting text into numbers that capture meaning. "deep learning" and "neural networks" get similar numbers because they mean similar things. Like a barcode that represents what a paper is about.

Cosine Similarity

Measures the angle between two vectors. Score close to 1 = very similar meaning. Score close to 0 = unrelated. Used to find which papers are most similar to the user's question.

RAG

Retrieval Augmented Generation. Instead of asking AI to know everything, you first retrieve relevant documents, then give them to the AI as context. More accurate, less hallucination.

Semantic Search

Understands meaning not just keywords. Searching "image recognition" finds CNN papers even if "CNN" isn't in the query — because the meanings are similar.

Serverless

No servers to manage. Lambda runs your code only when needed, scales automatically to any number of users, and you pay only for what you use. Zero idle cost.

CI/CD

Continuous Integration / Continuous Deployment. Every code change automatically tested and deployed. No manual uploading — push code and it's live in 60 seconds.
